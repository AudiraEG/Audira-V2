# AUDIRA website concept

Financial Intelligence & Technology Group. Arabic (RTL) and English (LTR), dark and light themes.

- `audira_site_final.html`: standalone single-file site. Open it in any browser.
- `hosted-app/src`: source of the hosted version (TypeScript entry, HTML body, CSS, fonts, images).
- `generator/`: the Python and JS sources that generate both outputs (`python3 build5.py`). Paths inside `build5.py` point to the original workspace and need adjusting.

Placeholders (WhatsApp number, email, [XXX] prices, founding story, sample figures) are marked on the page and must be replaced before launch.
